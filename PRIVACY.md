# MindNative privacy policy

Last updated: 11 October 2026.

MindNative keeps maps and attachments in files that you select.
The app does not send this content to a MindNative server.

## Data use

- Apple Intelligence processes requests on your Mac through the Foundation Models framework.
- If you save a map in iCloud Drive, Apple keeps copies of the file through your iCloud account.
- Calendar and Reminders receive an idea only after you select an export action and give permission for access.
- A link preview sends a request to the linked website.
- An update check sends a request to GitHub.
- Share and print actions use the macOS services that you select.

MindNative has no account system, advertisements, or user activity analytics.
The app does not use third-party crash reports.
Diagnostic logs do not contain map titles, notes, prompts, or attachment content.

## Permissions

The app requests Calendar or Reminders access when you select the applicable export action.
You can use the other functions without these permissions.
The macOS App Sandbox controls access to files and attachments that you select.

## Local copies

The app keeps recovery copies in its local data folder.
These copies can contain map content and attachments.
The app can also create temporary copies for attachment access and PDF share actions.

## Delete data

Delete map files with Finder.
If you use iCloud Drive, remove the applicable copies there.
Remove exported events and reminders in Calendar and Reminders.

Map deletion does not remove recovery copies.
To remove a recovery copy, first close MindNative.
Then delete the copy from the `MindNative/Recovery` folder in the app's local data folder.

## Contact

Send privacy questions through [GitHub Issues](https://github.com/SirwanAfifi/mindnative/issues).
Do not include private map content in a public issue.
