# Website assets

The project map and blank canvas images are app screenshots supplied by Sirwan Afifi on 2026-10-11.
Each image uses lossless WebP at its original size of 2464 by 1744 pixels.
The conversion keeps the pixels, transparency, and color profile.
The images have no crop, retouching, or generated content.
Each WebP image has an origin sidecar with the source file name and SHA-256 hash.
A PNG copy of the project map is used for link previews. Its origin is embedded.
The app icon comes from the existing MindNative icon. The WebP copy is 96 pixels square. The favicon is 32 pixels square.

Manrope comes from the Google Fonts repository at https://github.com/google/fonts/tree/main/ofl/manrope.
The font uses the SIL Open Font License. See fonts/OFL.txt.
