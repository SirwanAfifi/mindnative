# Website assets

The editor, radial, and presentation images are existing MindNative app screenshots.
They came from this project's original landing-page assets and match the public repository's docs/images screenshots.
The app icon comes from the existing MindNative icon. The WebP copy is 96 pixels square. The favicon is 32 pixels square.
