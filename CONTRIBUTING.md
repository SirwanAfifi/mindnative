# Contribute to MindNative

Use Xcode 26 or later.
See [Build and test](docs/BUILD.md) for the test commands.

## Problem reports

1. Open a [GitHub issue](https://github.com/SirwanAfifi/mindnative/issues).
2. Give the macOS version and app version.
3. Give the steps that cause the problem.
4. Give the expected test result and the actual test result.

Remove private content from screenshots and sample maps before you attach them.

## Send a change

1. Fork the repository.
2. Make a branch for one change.
3. Make the change.
4. Run the applicable tests.
5. Open a pull request.

Give the problem, the change, and the test results in the pull request.
If you change app behavior, update the applicable documentation.
Use short sentences, direct instructions, and the same technical terms in documentation.
Keep legal license text unchanged.
