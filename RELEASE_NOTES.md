# Release notes

## MindNative 1.0 source code

This version contains the source code for MindNative 1.0.
A packaged app release is not yet available.

### Functions

- Make map ideas with notes, tags, links, tasks, images, and attachments.
- Add branches and cross-links.
- Collapse branches or show one branch at a time.
- Search ideas with the Navigator.
- Change layouts or use presentation mode.
- Make ideas with Apple Intelligence or a built-in idea list.
- Share, print, and use Shortcuts.
- Export selected ideas to Calendar and Reminders.
- Import and export Markdown, OPML, FreeMind, and XMind files.
- Export PNG, PDF, and SVG files.
- Restore recovery copies and resolve document conflicts.
- Copy branches between documents.

### Requirements

The app targets macOS 13.0 or later.
Apple Intelligence requires macOS 26 or later and a compatible Mac.
The source code requires Xcode 26 or later.
